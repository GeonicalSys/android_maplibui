title: Начальные значения категории сохраняются в фоновой записи
why: Разные способы создания обходили общий выбор типа и теряли начальные значения до открытия атрибутов
---

Общий диалог сохраняет исходный способ создания при пересоздании. Выбранные
значения нового обхода записываются вместе с его геометрией и владельцем, затем
переносятся в черновики геометрии и формы. Существующие объекты не получают
начальные значения нового объекта.
